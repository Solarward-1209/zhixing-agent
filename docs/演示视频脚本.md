# 演示视频脚本（5~8 分钟，1080p，普通话讲解）

> 录制建议：OBS Studio（免费）或 Win+G 游戏条。分辨率 1920×1080，浏览器缩放 100%，
> 关闭无关标签页与通知。先按本脚本排练 1 遍再正式录。总时长目标 6 分 30 秒左右。

## 开场（0:00 – 0:40）

**画面**：浏览器打开应用空白首页（http://localhost:5173 或线上部署地址）

**口播**：
> 大家好，我们是____团队（填你的队名）。我们的作品是「知行 Agent」——一个会规划、会查证、会使用工具的
> 透明化 AI 智能助手，参加 AI Agent 智能助手赛道。
> 它最大的特点是：AI 回答一个问题的完整过程——怎么理解、怎么规划、查了什么资料、调用了什么工具——
> 全部实时展示给用户，结论都附带可溯源的引用。

## 功能演示一：赛事问答 + RAG（0:40 – 2:20）

**画面**：点击示例问题「传智杯的报名截止时间是什么时候？评审标准是怎样的？」

**口播**（回答流式输出时同步讲）：
> 我先问一个备赛中最典型的问题。注意看，回答生成之前，右侧出现了「Agent 执行计划」——
> 系统把这个问题拆解成了三步：理解问题、检索知识库、组织回答。
> 这里有一个知识库工具卡片，显示它从内置的传智杯备赛知识库里召回了 3 条相关内容。
> 知识库一共 15 篇，内容整理自大赛官网的赛道详情页，覆盖报名、组别、评分、提交、奖项全部章节。
> 回答出来了：每一条关键信息后面都有引用编号，底部是「引用来源」卡片，鼠标悬停还能看到原文摘要。
> 这就解决了通用大模型"一本正经编造答案"的痛点——我们的结论是有据可查的。

## 功能演示二：Agent 自主规划 + 多工具协同（2:20 – 4:00）★核心亮点

**画面**：输入「作品提交需要准备哪些材料？在线演示有什么要求？」

**口播**：
> 接下来是这个作品最核心的亮点。这个问题看起来是纯咨询问题，但请注意计划时间线——
> 模型除了检索知识库之外，<b>自主决定</b>额外调用了一次时间工具。
> 为什么？因为回答"什么时候该做什么"，需要知道今天几号、距离截止还有多久。
> 我们没有硬编码任何规则，这是大模型基于 Function Calling 的自主决策。
> 看回答：它列出了代码仓库、演示视频、技术文档、在线演示四类材料要求，并且算出了
> "距离 11 月 18 日提交截止还有约 50 天"——多工具协同加上日期推理，这是 Agent 能力的直接体现。

**画面**：再输入「帮我算一下 (128*46+372)/4 等于多少」

> 工具调用也覆盖精确计算。大模型直接心算复杂数学容易出错，所以我们要求它必须调用本地计算工具——
> 一个递归下降解析器——结果精确可靠，并且渲染成专门的计算卡片。

## 功能演示三：图片理解 + 安全兜底（4:00 – 5:00）

**画面**：点击📷按钮，上传一张赛事截图/评分表图片，提问「图片里的评审权重是怎样的？」

> 多模态方面，支持发送图片提问。图片会通过独立的视觉模型通道解读，同样以流式方式回答。
> （如果未配置视觉 Key，则演示优雅降级话术，说明"配置 VISION_API_KEY 即可启用"——产品对未配置状态的
> 处理也是设计的一部分。）

**画面**：输入一个风险问题（如"网上赌博平台推荐"）

> 安全方面：风险话题在输入侧就被拦截，统一返回拒绝话术，不会进入任何模型调用；
> 涉及医疗、法律、投资类内容会自动追加免责声明；模型或网络异常时有兜底话术，用户永远看到友好的反馈。

## 工程与技术架构（5:00 – 6:00）

**画面**：切到 GitHub 仓库页面（github.com/Solarward-1209/zhixing-agent），滚动 README

**口播**：
> 简单介绍技术架构。前端 React 18 + Vite + Tailwind CSS，严格模式 TypeScript；
> 服务端是 Node 上的 Agent 编排器，通过九类 SSE 事件与前端通信——计划、步骤、工具调用、token、引用来源，
> 全部事件化。RAG 采用 BM25 加向量混合检索，可插拔升级。接入层兼容智谱、DeepSeek 等 OpenAI 兼容模型。
> 质量保障方面：38 项单元测试覆盖工具、检索、安全与完整流水线，GitHub Actions 在每次提交时自动执行
> 类型检查、测试和构建。仓库保留了完整的提交历史，体现真实的开发过程。

## 收尾（6:00 – 6:30）

**画面**：回到应用，展示执行计划时间线特写

**口播**：
> 总结一下：知行 Agent 把 AI 从"黑盒聊天框"变成"透明、可信、有据可查的智能助手"。
> 它的技术方案与大赛评审标准逐项对应，未来还会接入 MCP 生态和浏览器端推理。
> 知你所问，行你所托。谢谢观看。
